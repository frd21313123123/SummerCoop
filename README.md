# SummerCoop

[![Build SummerCoop](https://github.com/frd21313123123/SummerCoop/actions/workflows/build.yml/badge.svg)](https://github.com/frd21313123123/SummerCoop/actions/workflows/build.yml)

Экспериментальный мультиплеерный мод для **My Summer Car** на 2–4 игроков. Хост рассчитывает физику и подтверждает действия; автомобиль, деньги и прогресс общие. Положение и потребности каждого игрока личные. Подключение предусмотрено через LAN/VPN или Steam-лобби.

**0.1.5-alpha исправляет причины блокировки хоста после подключения, продолжение действий клиента и рассинхрон количества пива.** Загрузка гостя больше не останавливает хоста и не запускает нативное сохранение. После готовности сцены лобби открывается без прежнего таймера в 10 секунд. Снимок мира сжимается и сериализуется в фоне; личные анимации выполняются у действующего игрока после подтверждения хоста. Посадка, шлем и индикатор передачи остаются локальными. Прошли 81 тест ядра, 12 тестов установщика и 12 проверок на реальных управляемых классах игры. Эти тесты не воспроизводят Unity-физику и не подтверждают полное совместное прохождение или 60 FPS. Метод, результаты и ограничения: [JOIN-INTERACTIONS.md](docs/JOIN-INTERACTIONS.md). Предыдущие игровые проверки: [NATIVE-MENU.md](docs/NATIVE-MENU.md), полная матрица: [QA](docs/QA.md).

По запросу пользователя изучен [MWCoop для My Winter Car](https://www.nexusmods.com/mywintercar/mods/3180) как ориентир для синхронизации. Сравнение архитектуры, применённые изменения SummerCoop и критерии проверки: [REFERENCE-MWCOOP.md](docs/REFERENCE-MWCOOP.md).

## Быстрая установка через EXE

Скачайте [SummerCoop-Setup.exe](https://github.com/frd21313123123/SummerCoop/releases/download/v0.1.5-alpha/SummerCoop-Setup.exe) и запустите его. Распаковывать архив и вводить команды PowerShell не требуется.

1. Закройте My Summer Car. Если загрузчик ещё не установлен, установите [MSCLoader 1.3.5](https://github.com/piotrulos/MSCModLoader/releases/tag/v1.3.5), выбрав каталог **Game Folder**.
2. Запустите EXE: он найдёт игру в библиотеках Steam. Проверьте выбранную папку; при необходимости нажмите «Обзор».
3. Нажмите **«Установить»**. Для отдельного мира хоста укажите его каталог `world` в поле профиля. Обычно достаточно пути по умолчанию.
4. Дождитесь «Готово», запустите игру через Steam. Меню SummerCoop открывается клавишей **F6**.

Если появляется окно **MSCLoader Update**, закройте его кнопкой **No** перед проверкой предметов и дверей: открытое окно загрузчика может блокировать игровые взаимодействия. Штатное меню игры открывается **Escape**, закрывается **Resume**.

В EXE встроена сборка `0.1.5-alpha`; он работает без скачивания DLL и доступа к приватному GitHub. Обновите мод **у хоста и всех клиентов**, используя тот же EXE. Обе DLL должны совпадать у всех игроков. Сам загрузчик MSCLoader в установщик не включён.

По умолчанию установщик отключает другие моды и их библиотеки, сохраняя DLL вне `Mods` в `SummerCoop-disabled-mods/setup-…/disabled`. Настройки и ресурсы остаются на месте; служебные моды MSCLoader Console/Settings сохраняются. Снимите флажок, если хотите оставить сторонние моды, однако совместимость с текущей alpha не проверена. Другие мультиплеерные загрузчики и графические инжекторы отключаются отдельно по инструкции ниже.

Старые DLL лежат в `setup-…/previous`, а при изменении сборки существующего мира его файлы — в `setup-…/profile`. Установщик выполняет проверенное обновление совместимой схемы v2 до замены DLL; при ошибке восстанавливает затронутые файлы. При несовместимых DLL, игре или профиле установка прекращается. Одиночное прохождение не меняется. Если папка игры защищена от записи, запустите EXE от имени администратора. Сумма EXE опубликована рядом в `SummerCoop-Setup.exe.sha256`.

Подробности, восстановление резервной копии и результаты проверок: [INSTALLER.md](docs/INSTALLER.md).

Следующие разделы описывают требования, ручную установку и подключение.

## Требования

| Компонент | Конфигурация сборки и прежних проверок |
| --- | --- |
| ОС | Windows |
| Игра | My Summer Car из Steam, build 20171487, v.250908-04 |
| Загрузчик | Компиляция 0.1.5-alpha с MSCLoader 1.4.2; прежние игровые проверки 0.1.3-alpha с 1.3.5 и частично 1.4.2 |
| Игроки | Одинаковые версия игры, игровые ресурсы и обе DLL SummerCoop |
| Другие моды | Отключены; совместимость не проверена |
| Steam | Отдельный аккаунт и купленная копия игры у каждого участника |
| LAN/VPN | Доступный IPv4 хоста, TCP и UDP на одном порту; по умолчанию 27842 |

Другие версии игры и загрузчика не считаются проверенными. Для испытаний используйте копию игры и резервную копию прохождения.

## 1. Найдите игру и сохраните прохождение

Закройте игру. В Steam откройте библиотеку → My Summer Car → свойства → «Установленные файлы» → «Обзор». Нужна папка, содержащая `mysummercar.exe` и `mysummercar_Data`.

Скопируйте каталог одиночных сохранений в безопасное место:

```text
%USERPROFILE%\AppData\LocalLow\Amistech\My Summer Car
```

Желательно также сделать отдельную копию игровой папки. SummerCoop использует собственные профили, но полное сохранение всех игровых подсистем ещё проверяется.

## 2. Установите MSCLoader

Если MSCLoader уже работает в выбранной игровой копии, повторная установка не нужна.

Скачайте его из [официального репозитория](https://github.com/piotrulos/MSCModLoader/releases). Проверенный выпуск — [1.3.5](https://github.com/piotrulos/MSCModLoader/releases/tag/v1.3.5). Следуйте [официальной инструкции установки](https://github.com/piotrulos/MSCModLoader/wiki): выберите My Summer Car и её `mysummercar.exe`.

**Выберите каталог модов в папке игры — Game Folder.** В этой версии отдельный каталог модов в Documents/AppData не поддерживается проверкой ванильной конфигурации. Mod Loader Pro вместо MSCLoader не проверен.

После установки ожидается такая структура:

```text
My Summer Car/
├─ mysummercar.exe
├─ doorstop_config.ini
├─ winhttp.dll
├─ mysummercar_Data/Managed/
│  ├─ MSCLoader.dll
│  └─ MSCLoader.Preloader.dll
└─ Mods/
   ├─ Assets/
   └─ References/
```

Запустите игру один раз, убедитесь, что MSCLoader загружается, затем закройте её.

## 3. Отключите остальные моды

Перенесите сторонние DLL из `Mods` и ненужные библиотеки из `Mods/References` в резервную папку **вне Mods**. Не удаляйте MSCLoader, его `winhttp.dll`, `doorstop_config.ini`, файлы в Managed и служебные ресурсы MSCLoader_Console / MSCLoader_Settings.

Другой мультиплеерный мод, включая WreckMP, должен быть отключён вместе с его загрузчиком. Для проверенной конфигурации также отключите ReShade и другие графические инжекторы. Их настройки и ресурсы можно сохранить.

EXE отключает сторонние DLL при включённом флажке. Ручная установка и PowerShell-скрипт ниже только копируют две DLL SummerCoop.

## 4. Скачайте готовую сборку

Готовая сборка — [SummerCoop-0.1.5-alpha.zip](https://github.com/frd21313123123/SummerCoop/releases/download/v0.1.5-alpha/SummerCoop-0.1.5-alpha.zip). Включены исправления подключения без паузы, действий клиента, посадки и количества пива. Проверки нового выпуска описаны в [JOIN-INTERACTIONS.md](docs/JOIN-INTERACTIONS.md). Стабильные 60 FPS без фризов не подтверждены; предыдущие замеры приведены в [документации производительности](docs/PERFORMANCE.md). Старые сборки сохранены в [Releases](https://github.com/frd21313123123/SummerCoop/releases). **Code → Download ZIP скачивает исходники, готовых DLL в нём нет.**

Если готовый выпуск ещё не опубликован, соберите установочный ZIP по разделу «Сборка и GitHub Actions» ниже. Текущий GitHub Actions проверяет ядро и публикует отчёт тестов; установочного архива в его артефактах нет.

У приватного репозитория доступ есть только у владельца и приглашённых участников. Все игроки должны использовать **один и тот же архив**: самостоятельно пересобранные DLL могут отличаться даже при одинаковой строке версии.

## 5. Установите две DLL

### Вручную

Скопируйте содержимое каталога Mods из готового архива в Mods игровой папки, сохраняя структуру:

```text
My Summer Car/
├─ mysummercar.exe
└─ Mods/
   ├─ SummerCoop.dll
   └─ References/
      └─ SummerCoop.Core.dll
```

Обе DLL обязательны. Не создавайте лишний вложенный каталог вроде `Mods/SummerCoop/Mods`. Core должна находиться именно в References.

### Через PowerShell-скрипт

Откройте PowerShell в распакованном **готовом выпуске**, где лежит install.ps1:

```powershell
.\install.ps1 -GamePath 'E:\SteamLibrary\steamapps\common\My Summer Car'
```

Замените путь на свой. Установщик проверит игру и MSCLoader, потребует закрыть выбранный игровой процесс, сохранит предыдущие DLL SummerCoop с суффиксом `.before-summercoop` и скопирует новые. Исходные одиночные сохранения он не меняет.

При обновлении уже существующего мира хоста используйте установщик **до ручной замены DLL**. Он проверяет сохранение по старым установленным DLL и ресурсам игры, создаёт отдельные резервные копии DLL и профиля, затем обновляет совместимую контрольную точку схемы v2. Идентификатор мира, детали, деньги и нативные файлы сохраняются. При несовместимости обновление прекращается без замены DLL. Для нестандартного каталога мира добавьте `-ProfilePath 'D:\MyCoop\world'`. Клиент получает мир заново от хоста и не требует переноса локального клиентского профиля.

После обновления передайте другу **тот же EXE или установочный ZIP** и обновите обе стороны. Совпадения надписи версии недостаточно: сборки проверяются по хешам DLL. Если ручная замена уже выполнена, восстановите прежние DLL из резервной копии перед запуском установщика; не удаляйте профиль для обхода ошибки версии.

Если Windows блокирует скачанный файл, проверьте источник и SHA-256, затем используйте «Разблокировать» в свойствах файла. Если PowerShell запрещает выполнение скрипта, установите DLL вручную; изменение системной политики не требуется.

## 6. Создайте сессию

Запустите игру обычным способом через Steam. В главном меню должна появиться панель **SummerCoop 0.1.5-alpha**. Клавиша **F6** показывает и скрывает её. **Escape** открывает штатное меню паузы каждого игрока; кнопка **Resume** закрывает его. Начинайте сессию через панель SummerCoop, а не через обычную загрузку одиночного сохранения.

### Хост LAN / VPN

1. Укажите имя, порт и при необходимости пароль LAN.
2. Чтобы начать из одиночного прохождения, отметьте «Создать мир из копии одиночного сохранения». Импорт работает только при первом создании профиля.
3. Нажмите «Хост LAN / VPN» и дождитесь загрузки.
4. Передайте друзьям IPv4 своего компьютера в локальной или виртуальной VPN-сети, порт и пароль. `127.0.0.1` подходит только для процессов на одном компьютере.
5. Разрешите входящие **TCP и UDP** на выбранном порту в брандмауэре для доверенной сети.

### Подключение LAN / VPN

У клиента должны быть установлены те же игра, MSCLoader и обе DLL из того же ZIP. В главном меню он вводит «IP хоста», «Порт», «Пароль LAN» и нажимает «Подключиться LAN / VPN».

После входа хоста в готовый мир друг уже может подключаться. Передаются сжатая нативная копия для загрузки сцены и актуальный снимок мира. Хост продолжает играть, пока друг загружает сцену; изменения за это время догоняют клиента после снимка. Клиент начинает играть после получения общего состояния. LAN-транспорт не шифруется и предназначен для доверенной сети/VPN: не публикуйте этот порт напрямую в интернет.

### Steam-лобби

Запустите Steam и включите оверлей. Хост нажимает «Хост через Steam», после создания лобби — «Пригласить друзей через Steam». Клиент принимает приглашение или вводит номер в «Steam lobby» и нажимает «Подключиться к Steam lobby».

Если Steam недоступен, кнопка хоста отключена. Создание лобби и подготовка сохранения проверены в игре на одном аккаунте; приглашения и передача через Steam P2P между аккаунтами ещё требуют проверки. Для проверки передачи мира между двумя игровыми процессами используется LAN/VPN.

## Сохранения, сон и выход

В панели доступны голосование сна, «Возродиться дома» и «Закрыть сессию». Для пропуска времени нужна готовность всех подключённых игроков. Выход хоста заканчивает сессию; переноса хоста нет.

Профили находятся здесь:

```text
%USERPROFILE%\AppData\LocalLow\Amistech\My Summer Car\SummerCoop\world
%USERPROFILE%\AppData\LocalLow\Amistech\My Summer Car\SummerCoop\client
```

В world хранятся нативные файлы, контрольная точка world.scw, её резервная копия и журнал world.scj. Копируйте **весь каталог профиля при закрытой игре**. Импорт создаёт отдельную копию одиночного сохранения; обратная запись в него не предусмотрена. Выключение флажка импорта не обнуляет существующий мир.

Для отдельного тестового профиля добавьте в параметры запуска Steam:

```text
--summercoop-profile "D:\SummerCoop-test"
```

Не переносите профиль между несовместимыми сборками без резервной копии. Миграция между разными версиями протокола не реализована.

## Обновление и удаление

Закройте игру, сохраните копию профиля и замените **обе** DLL файлами из одного нового архива. Все участники обновляются одновременно.

Обновление изменяет хеш сборки. Для этой оптимизации с той же нативной схемой v2 предусмотрен исходный инструмент `tools/MigrateProfile.cs`: он проверяет старые DLL и ресурсы игры, создаёт полную резервную копию файлов профиля и меняет только хеш совместимой сборки. Это не миграция между разными версиями игры или схемы; обычная замена DLL сама профиль не переносит.

Для удаления уберите Mods/SummerCoop.dll и Mods/References/SummerCoop.Core.dll либо выполните из готового выпуска:

```powershell
.\install.ps1 -GamePath 'E:\SteamLibrary\steamapps\common\My Summer Car' -Uninstall
```

Удаление мода не удаляет его профиль. Отключённые сторонние моды можно вернуть из резервной папки при закрытой игре; не используйте их одновременно с текущей alpha.

## Решение проблем

| Проблема | Проверка |
| --- | --- |
| Нет панели, F6 не работает | MSCLoader загружается; выбран Game Folder; нет лишнего вложенного Mods; присутствуют обе DLL |
| Пустое штатное меню не закрывается; клиент не может брать предметы | Закройте игру и обновите обе стороны одним установщиком 0.1.5-alpha, чтобы восстановить старые записи меню в профиле хоста. Сохранение не нужно удалять. Прежние игровые результаты: [NATIVE-MENU.md](docs/NATIVE-MENU.md) |
| После подключения хост не может ходить; клиент не может пить или сесть на мопед | Обновите обе стороны одним установщиком 0.1.5-alpha. Убраны сохранение и пауза при подключении, изолированы флаги управления и анимации игрока, защищён локальный ввод посадки: [JOIN-INTERACTIONS.md](docs/JOIN-INTERACTIONS.md) |
| В упаковке пива разное количество бутылок | В 0.1.5-alpha количество берётся из нативного счётчика хоста, а клиентская анимация не расходует бутылку повторно; обновите обе стороны |
| Не загружается SummerCoop.Core | Файл лежит в Mods/References; обе DLL взяты из одного архива |
| Обнаружены другие моды | Уберите сторонние DLL и отключите другой мультиплеерный загрузчик |
| Не совпадает игра / мод / схема | Игра, ресурсы и обе DLL должны совпадать; используйте один ZIP |
| LAN не подключается | Хост создал сессию; верны IP/порт/пароль; доступны TCP и UDP; VPN работает у обоих |
| Соединение есть, мир загружается | Дождитесь передачи снимка и Playing у клиента; хост может продолжать играть |
| FPS падает после создания сессии | Обновите обе DLL одновременно; результаты оптимизации и оставшиеся длинные кадры описаны в [PERFORMANCE.md](docs/PERFORMANCE.md) |
| В Actions нет ZIP полного мода | CI проверяет ядро; обе DLL и установочный архив собираются локально по инструкции ниже |
| Профиль несовместим после обновления | Восстановите совместимую сборку и резервную копию либо создайте отдельный тестовый профиль |

Логи Unity/MSCLoader находятся в игровой папке или mysummercar_Data/output_log.txt в зависимости от настроек запуска. Ошибки SummerCoop также пишутся в errors.log в корне его профилей.

В [Issues](https://github.com/frd21313123123/SummerCoop/issues) укажите версии, тип соединения, число игроков, действия хоста/клиента и шаги воспроизведения. Уберите из логов IP-адреса, пароли и личные данные.

## Сборка и GitHub Actions

Нужны Windows, Git, компилятор .NET Framework 4 и собственная игра с MSCLoader. Современный .NET SDK не обязателен.

```powershell
git clone https://github.com/frd21313123123/SummerCoop.git
cd SummerCoop
.\tools\build.ps1 -GamePath 'E:\SteamLibrary\steamapps\common\My Summer Car'
.\tools\package.ps1
```

Результат: две DLL в build, build/test-results.txt, установочные ZIP и **dist/SummerCoop-Setup.exe** с SHA-256. EXE упаковывает уже собранные DLL без их повторной компиляции. Полная сборка использует C# 5, Mono BCL и сборки именно вашей игры. Игровые DLL в репозиторий и архивы не включаются.

Проверки ядра можно выполнить без игры:

```powershell
.\tools\build.ps1 -TestsOnly
```

Эта команда создаёт только ядро и тестовый EXE; для игрового мода используйте полную сборку.

Проверки установщика запускаются отдельно и не перезаписывают игровые DLL:

```powershell
.\tools\test-installer.ps1
```

После полной сборки можно проверить поля и сигнатуры настоящих игровых действий без запуска игры:

```powershell
.\tools\test-native-bindings.ps1 -GamePath 'E:\SteamLibrary\steamapps\common\My Summer Car'
```

Проверяется тот же анализатор действий, который используется модом, с классами из вашей игры. Это проверка управляемых привязок; движок Unity, физика, анимации и реальный ввод в ней не запускаются. Игровые DLL остаются в игнорируемом каталоге build и не публикуются.

После каждого push GitHub Actions компилирует ядро, проверяет транзакции установщика и собирает его интерфейс на windows-latest. Для проверки EXE в CI используются явно помеченные тестовые файлы, такой EXE не публикуется. Локальный runner отключён по просьбе владельца. Полная сборка обеих игровых DLL и готового установщика требует сборок установленной игры и MSCLoader и выполняется локально командами выше. Подробности описаны в [docs/CI.md](docs/CI.md).

## Исходный код

- src/Core — протокол, сессии, LAN, владение предметами/сиденьями и сохранение модели.
- src/Game — MSCLoader, Steam, объекты сцены, PlayMaker, физика и отображение.
- tests — проверки протокола, состояния и транспорта.
- tools — сборка, упаковка, установка и испытания изолированных игровых копий.
- docs — [архитектура](docs/ARCHITECTURE.md), [игровые проверки](docs/QA.md), [CI](docs/CI.md).
