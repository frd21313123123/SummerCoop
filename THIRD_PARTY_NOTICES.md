# Third-party source and assets

`vendor/MWCoop` contains source and assets from [Parricidium/MWCoop](https://github.com/Parricidium/MWCoop), revision `25f322a749f53f2dca16b09c14165ae64709a9db` (0.95.3). Its authorship and asset credits are retained in [the original README](vendor/MWCoop/README.md); provenance and local changes are described in [UPSTREAM.md](vendor/MWCoop/UPSTREAM.md).

The upstream revision contains no explicit LICENSE file. The MIT license in this repository applies to the SummerCoop authors' code and does not grant additional rights over the upstream portions. Game assemblies and MSCLoader binaries remain external build dependencies.

`launcher/MwStyle.cs` and the layout in `launcher/MwLauncherView.cs` adapt the upstream launcher drawing, palette and geometry from `launcher/ui.inc`, `launcher/uikit.inc` and `launcher/launcher.cpp` at that same revision. The upstream rights notice above also covers these derived portions.
