## ru

- Кнопки создания ящиков с гаечными ключами и трещотками перенесены из меню F10 прямо в панель «Читы» (F7 по умолчанию). Хост может создать набор перед собой без перехода в другое меню.
- Просмотр и удаление дополнительных ящиков доступны через кнопку «Ящики с инструментами».

## en

- Moved the spanner and ratchet case spawn buttons from the F10 menu directly into the cheat panel (F7 by default). The host can spawn a set in front of them without opening another menu.
- Extra cases can still be viewed and deleted through the Tool cases button.
