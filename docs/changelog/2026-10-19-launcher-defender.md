## ru
- Лаунчер больше не запускает PowerShell для поиска антивирусов и скрытую командную оболочку для самоудаления. После удаления данных файл лаунчера можно удалить вручную; это указано в окне удаления.
- Справка по антивирусу больше не предлагает исключать всю папку игры и не объявляет обнаружение заведомо ложным.
- Перед публикацией проверяются готовый EXE и обе DLL мода в Microsoft Defender; при обнаружении угрозы или ошибке проверки выпуск останавливается. Проверка одной сборки не гарантирует отсутствие будущих срабатываний.

## en
- The launcher no longer starts PowerShell to enumerate antivirus products or a hidden command shell to delete itself. After data removal, the launcher file can be deleted manually as explained in the uninstall dialog.
- Antivirus help no longer recommends excluding the entire game folder or assumes a detection is a false positive.
- The final EXE and both mod DLLs are scanned with Microsoft Defender before publication; detections and scan errors block release. A clean scan of one build does not guarantee future detection results.
