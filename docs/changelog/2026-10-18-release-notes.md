## ru
- В «Что нового» теперь публикуются понятные описания изменений для каждого нового выпуска, с кратким списком на главном экране.
- GitHub Releases автоматически получает заметки на русском, английском и французском. Если отдельного описания нет, используется список коммитов после предыдущего выпуска.
- В истории изменений исправлена отметка установленной версии лаунчера. Заголовки, списки и ссылки отображаются как читаемый текст.

## en
- New releases now have readable descriptions in What's new, with a short list of changes on the home screen.
- GitHub Releases automatically includes Russian, English and French notes. Releases without a dedicated description use commits since the previous published release.
- Fixed the installed launcher version indicator in the release history. Headings, lists and links are displayed as readable text.

## fr
- Les nouveautés de chaque version sont décrites dans le lanceur, avec un résumé sur l'écran d'accueil.
- GitHub Releases reçoit automatiquement les notes en français, anglais et russe. Sans description dédiée, les commits depuis la version publiée précédente sont utilisés.
- L'indicateur de version installée du lanceur est corrigé dans l'historique. Titres, listes et liens sont affichés sous forme de texte lisible.
