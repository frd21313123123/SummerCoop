# Заметки для выпусков

Для изменения, которое должно попасть в журнал, добавьте новый Markdown-файл
в эту папку, например `2026-10-18-release-notes.md`. После публикации сохраняйте
его как запись истории; для следующего изменения создавайте новый файл.

Обязательные секции — `## ru` и `## en`. Секция `## fr` необязательна:
если её нет, используется английский текст. Внутри пишите короткие пункты
о поведении, которое увидит игрок; можно использовать подзаголовки `###`.
Номер сборки заранее не нужен, при необходимости доступна подстановка
`{{version}}`.

```markdown
## ru
- Исправлено подключение к лобби после приглашения Steam.

## en
- Fixed joining a lobby after a Steam invitation.
```

GitHub Actions включает только заметки, добавленные или изменённые после
предыдущего опубликованного выпуска. Готовое описание попадает в GitHub
Release и раздел «Что нового» лаунчера. Если новых файлов заметок нет,
автоматически используется список последних 30 коммитов за этот период.
Повторная сборка без новых коммитов получает соответствующее пояснение.

Предпросмотр (укажите существующий тег предыдущего выпуска):

```powershell
./tools/release-notes.ps1 -Version 0.4.8.59 -Repository frd21313123123/SummerCoop -PreviousTag v0.4.8.58 -OutputPath build/release-notes-preview.md
```

Генератор читает зафиксированные файлы из выбранного коммита. Результат
сохраняется в UTF-8; дополнительные файлы рядом с пользовательским EXE
не нужны.
