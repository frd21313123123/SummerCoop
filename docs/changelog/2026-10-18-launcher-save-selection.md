## ru
- Исправлен выбор сохранений: игра использует мир, выбранный хостом в лаунчере и лобби, а список показывает настоящие сохранения My Summer Car.
- «Новая игра» сразу создаёт и выбирает отдельное сохранение для текущего лобби. Старые миры остаются доступны; пустые сохранения больше не заполняются прежним миром автоматически.
- Выбор старого мира переключает лобби на продолжение. В списке выбора доступны страницы для большого количества сохранений.
- Прежний общий мир остаётся в «Основной игре». При явном перезапуске сохранения сохраняется резервная копия; обновление лаунчера сохраняет выбранный слот, настройки и файлы миров.

## en
- Fixed save selection: the game uses the host's chosen world from the launcher and lobby, and the list detects actual My Summer Car saves.
- New game immediately creates and selects a separate save for the current lobby. Previous worlds remain available; empty saves no longer import the old world automatically.
- Choosing an existing world switches the lobby to Continue. The save picker supports multiple pages.
- The previous shared world remains under Main game. Explicit restarts keep a recovery copy; launcher updates preserve the selected slot, settings and world files.
