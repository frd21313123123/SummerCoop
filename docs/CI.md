# GitHub Actions

Workflow [build.yml](../.github/workflows/build.yml) запускается после каждого push, для pull request и вручную через Actions → Build SummerCoop → Run workflow.

На стандартной виртуальной машине GitHub `windows-latest` компилируется ядро с C# 5 и выполняется полный набор проверок, включая настоящие TCP/UDP-сокеты. Игра и её DLL этому этапу не нужны. Отчёт доступен в журнале шага и сводке запуска. Загрузка артефактов не используется: квота хранения аккаунта была заполнена, а для проверки ядра отдельный ZIP не нужен.

Текущий набор ядра содержит 81 проверку; все они прошли локально, включая настоящие TCP/UDP-сокеты. Проверяются также подключение без паузы хоста, сжатие с точным восстановлением, изменения во время загрузки, личные эффекты клиента, последовательные действия болтов, количество пива и посадка с потерянным UDP. `build/SummerCoop.Tests.exe --no-sockets` предназначен для ограниченной среды, явно пропускает только проверку настоящих сокетов и пишет `PARTIAL`. GitHub Actions запускает тесты без этого параметра и требует весь набор.

Отдельный шаг `tools/test-installer.ps1` проверяет поиск Steam-библиотек, установку, резервные копии, совместимое обновление профиля, восстановление при отказе миграции и при сбое после замены первой DLL, отказ при запущенной игре, повреждённом пакете и неверном загрузчике. Затем компилируется настоящий WinForms-интерфейс с явно инертными файлами вместо DLL мода. Такой EXE называется `DO-NOT-PUBLISH-fixture-Setup.exe` и не публикуется. Результаты установщика также попадают в сводку workflow.

Локальный runner удалён по просьбе владельца. Регистрации в GitHub, фонового процесса и автозапуска на компьютере нет.

## Полная сборка

Полная сборка мода требует Mono, Unity, PlayMaker, ES2, Steamworks и MSCLoader из установленной игры. Эти файлы не включены в репозиторий или артефакты CI. На стандартной машине GitHub их нет, поэтому текущий workflow не создаёт установочный ZIP и не проверяет компиляцию игрового адаптера.

Соберите мод на компьютере с установленной игрой и MSCLoader:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\build.ps1 -GamePath "E:\SteamLibrary\steamapps\common\My Summer Car"
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\package.ps1
```

Архивы и отдельный `SummerCoop-Setup.exe` с файлом SHA-256 появятся в `dist`. Установщик встраивает две готовые DLL и инструмент совместимого обновления профиля; игровых сборок в нём нет. Сборка не устанавливает мод в игру и не меняет сохранения. Инструкция установки находится в [README.md](../README.md), игровые проверки — в [QA.md](QA.md).

Действие `checkout` закреплено на SHA официального выпуска. Разрешения workflow ограничены `contents: read`.

Локальная команда `tools/test-native-bindings.ps1 -GamePath PATH` запускает 12 проверок анализа действий против настоящих управляемых классов PlayMaker и игры. Она не вызывает Unity-физику. Эти DLL нужны только локально, остаются в игнорируемом build и не передаются на GitHub. Подробности: [JOIN-INTERACTIONS.md](JOIN-INTERACTIONS.md).
