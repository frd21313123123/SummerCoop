# Установщик Windows

Готовый [SummerCoop-Setup.exe](https://github.com/frd21313123123/SummerCoop/releases/download/v0.1.0-alpha/SummerCoop-Setup.exe) содержит две DLL проверенной сборки `performance-packets` и вспомогательный EXE обновления совместимого мира. Скачивание DLL, PowerShell, регистрация сервисов и локальный GitHub runner ему не нужны. Установщик использует .NET Framework 4.x, входящий в Windows 10/11. MSCLoader устанавливается отдельно в режиме **Game Folder**.

Он читает расположение Steam из реестра, `libraryfolders.vdf` и манифест игры `516750`. Поддерживаются несколько библиотек, старый и новый формат VDF, пробелы и кириллица в путях. Найденную папку можно изменить через «Обзор». При нескольких установках выбирайте нужную копию в списке.

Перед записью проверяются файлы пакета по встроенным SHA-256, выбранная игра, MSCLoader, его каталог модов и отсутствие запущенной игры. Установщик не меняет конфигурацию загрузчика и не запускает игру. Папки с junction/символическими ссылками не поддерживаются: выберите их фактическую папку. Для защищённой игровой папки может потребоваться запуск от имени администратора.

По умолчанию сторонние DLL из каталога модов и библиотек сохраняются в `SummerCoop-disabled-mods/setup-…/disabled` и убираются из `Mods`. Служебные моды MSCLoader Console/Settings, настройки и ресурсы сохраняются. Флажок можно снять. Инжекторы и сторонние загрузчики вне `Mods` отключаются отдельно. Предыдущая пара SummerCoop сохраняется в `setup-…/previous`.

Если существует `world.scw` и DLL изменились, сначала копируются текущие файлы профиля в `setup-…/profile`, затем инструмент миграции проверяет старую сборку и ресурсы игры. Разрешено только обновление совместимой нативной схемы v2. При отказе или сбое затронутые DLL и файлы профиля восстанавливаются; резервные копии остаются. При совпадающей паре DLL повторная установка не мигрирует профиль. При нестандартном параметре игры `--summercoop-profile` укажите соответствующий подкаталог `world` в окне установщика.

Для восстановления сторонних модов при закрытой игре скопируйте содержимое `disabled` обратно в `Mods`, сохраняя подпапки. Старый мир и старые DLL восстанавливаются вместе, из одной резервной копии.

## Сборка и проверки

`tools/package.ps1` создаёт ZIP и самостоятельный EXE из уже собранных DLL. `tools/build-installer.ps1` позволяет собрать EXE отдельно из готового каталога выпуска, без повторной компиляции мода. SHA-256 EXE записывается рядом в `SummerCoop-Setup.exe.sha256`.

`tools/test-installer.ps1` проверяет 12 сценариев: Steam-библиотеки и манифесты, свежую установку, сохранение сторонних модов по запросу, повторную установку, обновление мира, отказ миграции, восстановление после частичной замены DLL, отсутствие старой пары DLL, повреждённый пакет, конфигурацию загрузчика, запущенную игру/конкурирующую установку и неверные пути. GitHub Actions выполняет эти проверки и компилирует интерфейс с инертными файлами, которые не публикуются как мод.

Готовый установщик дополнительно проверен на изолированной игровой копии с настоящими игровыми ресурсами: установка, миграция старой сборки `udp-buffer` и повторная установка прошли. Каноническое состояние мира до/после: `2f9fa2986a2b76de7ee5fbf5fcb50beb34ed7e7ad98b756ba013b9b6c140b446`, ревизия 635, 39 571 объект, деньги 3000. Нативные файлы совпали по SHA-256. Для автоматизации доступны команды ниже; обычная установка выполняется кнопкой в окне:

```powershell
Start-Process -Wait .\SummerCoop-Setup.exe -ArgumentList '--detect', '--log="D:\Coop\found-games.txt"'
Start-Process -Wait .\SummerCoop-Setup.exe -ArgumentList '--install', '--game="E:\SteamLibrary\steamapps\common\My Summer Car"', '--profile="D:\Coop\world"', '--log="D:\Coop\install.txt"'
```

Каталог для журнала должен существовать. Аргумент `--keep-other-mods` сохраняет сторонние DLL активными. Код выхода 0 означает успех; 1 — отказ или ошибку. В режиме без интерфейса отсутствие единственной найденной игры требует явного `--game`.
