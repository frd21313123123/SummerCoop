# SummerCoop Launcher

Лаунчер устанавливает SummerCoop и запускает My Summer Car с выбранным подключением.
Мод и фон встроены в один `SummerCoop-Launcher.exe`.

## Что умеет

- Три вкладки: **Играть / Настройки / Диагностика**.
- Один выбор режима и одна кнопка запуска: **«Создать игру»**, **«Присоединиться»**
  или **«Играть»** в зависимости от режима.
- Поля подключения зависят от режима: адрес хоста только для гостя LAN, порт и
  пароль только для LAN, номер лобби только для гостя Steam.
- Папка игры и сохранение мира задаются в одном месте — в настройках.
- Строка состояния внизу показывает результат действия или ошибку на любой вкладке.
- Режимы подключения:
  - `Хост LAN / VPN` → `--summercoop-host-lan PORT`
  - `Подключиться LAN / VPN` → `--summercoop-join-lan IP --summercoop-port PORT`
  - `Хост через Steam` → `--summercoop-host-steam yes`
  - `Подключиться к Steam-лобби` → `--summercoop-join-steam ID` (тот же эффект, что `+connect_lobby ID`)
  - `Выбрать подключение в игре (F6)` → запуск без сетевых аргументов.
- Имя игрока (`--summercoop-name`), пароль LAN (`--summercoop-password`) и импорт
  одиночного сохранения (`--summercoop-import-save yes`) передаются из лаунчера в мод.
  Импорт доступен при создании мира и запуске без подключения; при подключении к
  чужому миру аргумент импорта не передаётся.
- Проверка игры и MSCLoader, кнопка **«Установить мод»** / **«Обновить мод»** (тот же проверенный
  `Installer`, что в `SummerCoop-Setup.exe`: бэкапы, миграция мира, откат).
- Запуск двумя способами: напрямую через `mysummercar.exe` или через
  `steam.exe -applaunch 516750 <аргументы>`. В режиме `Авто` Steam-режимы идут через
  Steam, LAN — через EXE.
- Настройки хранятся в `%APPDATA%\SummerCoop\launcher.ini`, сохраняются при запуске,
  установке и закрытии окна. Есть отдельная кнопка **«Сохранить»**.
- Диагностика: действия лаунчера, последние 150 строк `errors.log`, `output_log.txt`,
  кнопки открытия папок сохранения и игры.
- CLI без окна: `--detect`, `--print-args --mode=host-lan|join-lan|host-steam|join-steam|solo ...`.

## Фон

Арт (`launcher/assets/background.png`) вшит прямо в EXE: лаунчер — один файл,
ничего рядом класть не нужно. Чтобы сменить задник без пересборки, положите свой
`background.jpg` / `background.png` / `background.jpeg` рядом с EXE (или в подпапку
`assets`) — внешний файл имеет приоритет. Идеальный размер 1920×1080.

## Сборка

Нужны Windows и `.NET Framework C# compiler` (как для мода). Полная цепочка:

```powershell
.\tools\build.ps1 -GamePath 'E:\SteamLibrary\steamapps\common\My Summer Car'
.\tools\package.ps1
```

`package.ps1` сам собирает `dist\SummerCoop-Setup.exe` и `dist\SummerCoop-Launcher.exe`.
Только лаунчер из готового пакета:

```powershell
.\tools\build-launcher.ps1
```

Проверки лаунчера (11 тестов ядра, компиляция GUI на фиктивном пакете и проверки
настоящих WinForms-элементов; фиктивный EXE не публикуется):

```powershell
.\tools\test-launcher.ps1
```

Константы версии в `launcher/LauncherCore.cs` (`LauncherInfo`) обязаны совпадать с
`src/Core/Model.cs` — это проверяет тест `launcher version constants match the mod protocol`.
GUI-проверки используют отдельный INI в `build`, проверяют загрузку сохранённых
параметров, все режимы, сохранение правок, ошибки ввода и отсутствие наложений
элементов при уменьшении окна. Снимки интерфейса сохраняются в
`build/launcher-tests/screenshots`; игра не запускается и мод не устанавливается.

## Использование

1. Запустите `SummerCoop-Launcher.exe` из любой папки.
2. Откройте **Настройки**: проверьте папку игры (находится в библиотеках Steam сама),
   профиль мира, способ запуска.
3. На вкладке **Играть** нажмите **«Установить мод»** / **«Обновить мод»** (первый раз и при каждом
   обновлении — у хоста и клиентов одна сборка).
4. На той же вкладке выберите режим, введите имя и показанные поля подключения.
5. Нажмите **«Создать игру»**, **«Присоединиться»** или **«Играть»**. Хост LAN открывает TCP+UDP на порту (по умолчанию 27842) или VPN
   (Radmin/ZeroTier). Хост Steam жмёт в игре приглашение друзей (Steam-оверлей).

Пароль в команде запуска в диагностике маскируется целиком (`***`), включая пробелы
и кавычки. Ошибка скрытого порта LAN не мешает запуску Steam-режимов.

## Файлы

- `launcher/LauncherCore.cs` — настройки, построение аргументов, маскировка пароля в диагностике.
- `launcher/BackgroundArt.cs` — загрузка `background.*`, встроенная заглушка.
- `launcher/MainForm.cs` — WinForms-интерфейс с полями для выбранного режима.
- `launcher/Program.cs` — вход, CLI `--detect` / `--print-args`.
- `launcher/app.manifest` — `asInvoker`, DPI-aware.
- `tools/build-launcher.ps1` — компиляция с вшитым payload мода.
- `tests/Launcher/LauncherTests.cs`, `tests/Launcher/LauncherUiTests.cs`, `tools/test-launcher.ps1` — проверки ядра и интерфейса.
