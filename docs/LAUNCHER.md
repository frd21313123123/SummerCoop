# SummerCoop Launcher

Разрешение читов переключается в игре: **F10 → ЧИТЫ → Разрешить читы**.
В сетевой игре настройку меняет хост, она применяется ко всем участникам
без перезапуска и сохраняется в общем INI. Панель читов открывается по **F7**
(либо по клавише, выбранной в настройках управления).

## Одежда и цвет автомобиля в нативном лаунчере

Вкладки **Одежда** и **Машина** доступны и при запущенной игре. Кнопки **OK**
и **Отмена** возвращают к экрану текущей игры; отмена восстанавливает прежние
значения. Выбор одежды передаётся в игру и остальным участникам без перезапуска.
Цвет Satsuma сохраняется для новой игры хоста, как указано на вкладке машины;
изменение этого параметра не перекрашивает уже загруженное сохранение.

Общий файл настроек — `<папка игры>\MWCoop\mwcoop.ini`; мод читает и сохраняет
его же, сохраняя данные мира и сетевые команды в изолированном профиле.
При запуске копии игры исходная папка передаётся через `--summercoop-launcher-dir`
и `LauncherDir` в `lancement.ini`. Настройки прежнего профиля подхватываются при
загрузке; существующий общий INI имеет приоритет.

Предпросмотры создаются в `<папка игры>\MWCoop\cache` после загрузки мира:
Satsuma — примерно через 20 секунд, персонаж — через 30 секунд. Открывать F10
для этого больше не требуется. Имя `corris.mesh` сохранено для совместимости
формата, но экспортируется Satsuma из MSC. Модели берутся из локальной игры.

Проверки (MSVC, собранный мод; для игровой проверки нужны подготовленные
изолированные `.local/game` и `.local/game-client`):

```powershell
.\tools\test-native-customization.ps1
.\tools\test-msc-adapter.ps1 -NoSockets
.\tools\test-customization-runtime.ps1
```

## Автопроверка версии в нативном лаунчере

Нативный `SummerCoop-Launcher.exe` проверяет выпуски
`frd21313123123/SummerCoop` при открытии и каждые 30 минут в меню.
Проверка выполняется в фоне, доступна без выбранной папки игры и не мешает запуску.
Текущая версия берётся из `mwversion.h`, который формируется при сборке.

При появлении новой версии под логотипом появляется **«Скачать · версия»**.
Кнопка открывает страницу конкретного выпуска GitHub. Скачайте новый EXE,
закройте старый лаунчер и запустите новый: в него уже встроены DLL мода.
Проверка сама не заменяет файлы. Поддерживаются релизные EXE лаунчера и ZIP мода;
архивы исходников и черновики исключены. Канал Stable исключает предварительные
версии, Nightly допускает их. Сравнение числовое: `0.4.10` новее `0.4.9`.

В **Настройки → Обновления** можно проверить версию вручную и отключить
автопроверку (`[Lanceur] CheckUpdates=0` в `summercoop-launcher.ini`, по умолчанию `1`).
Отсутствие сети, ограничение запросов GitHub и отсутствие выпусков имеют отдельные
состояния; ни одно из них не отображается как успешная проверка актуальности.
Кэш заметок при недоступном GitHub не используется как подтверждение новой версии.

Проверки реального нативного EXE (нужны MSVC и собранные DLL в `build`):

```powershell
.\tools\test-native-updates.ps1
```

## Автономная папка и сборка лаунчера

Готовый бинарник лаунчера собирается и хранится в отдельной автономной папке `SummerCoop-Launcher/`:
- Файл: `SummerCoop-Launcher/SummerCoop-Launcher.exe`.
- Лаунчер полностью самодостаточен: фоны, логотипы, иконка и библиотеки мода (`SummerCoop.dll`, `SummerCoop.Core.dll`) вшиты в ресурсы EXE. В папке `SummerCoop-Launcher/` должен находиться только сам исполняемый файл (дополнительно создаётся только рабочий `summercoop-launcher.ini` при запуске пользователем).
- Скрипт сборки `tools/build-launcher.ps1` компилирует лаунчер по умолчанию именно в эту папку (и синхронизирует копию в `dist/SummerCoop-Launcher.exe`).

Ниже сохранено описание прежнего интерфейса WinForms и общих возможностей установки.

Лаунчер устанавливает SummerCoop и запускает My Summer Car с выбранным подключением.
Мод встроен в один EXE; с 0.4.0 установка полностью встроена в лаунчер — отдельного
`SummerCoop-Setup.exe` больше нет. Начиная с 0.2.2 оформление и компоновка адаптированы из исходного лаунчера MWCoop 0.95.3.

## Что умеет

- Боковое меню: **Главная / Подключение / Как играть / Что нового / Журналы / Настройки**.
- Окно 1280×800 с уменьшением до 1024×640, стеклянные панели, летний фон из предыдущей версии SummerCoop, светлая и тёмная темы; выбранная тема сохраняется в INI.
- Один выбор режима и одна кнопка запуска: **«Создать игру»**, **«Присоединиться»**
  или **«Играть»** в зависимости от режима.
- Поля подключения зависят от режима: адрес хоста только для гостя LAN, порт и
  пароль только для LAN, номер лобби только для гостя Steam.
- Папка игры и сохранение мира задаются в одном месте — в настройках.
- Строка состояния внизу показывает результат действия или ошибку на любой вкладке.
- Приглашения из **F10 → Пригласить через Steam** появляются на странице **Главная**:
  имя отправителя, выбор приглашения, **«Принять и играть»** и **«Отклонить»**.
  При принятии выбранный номер лобби передаётся моду автоматически.
- Режимы подключения:
  - `Хост LAN / VPN` → `--summercoop-host-lan PORT`
  - `Подключиться LAN / VPN` → `--summercoop-join-lan IP --summercoop-port PORT`
  - `Хост через Steam` → `--summercoop-host-steam yes`
  - `Подключиться к Steam-лобби` → `--summercoop-join-steam ID` (тот же эффект, что `+connect_lobby ID`)
  - `Выбрать подключение в игре (F6)` → запуск без сетевых аргументов.
- Имя игрока (`--summercoop-name`), пароль LAN (`--summercoop-password`) и импорт
  одиночного сохранения (`--summercoop-import-save yes`) передаются из лаунчера в мод.
  Импорт доступен при создании мира и запуске без подключения; при подключении к
  чужому миру аргумент импорта не передаётся.
- Установка встроена в лаунчер: перед каждым запуском обе DLL сравниваются со сборкой лаунчера,
  и при расхождении мод устанавливается или обновляется автоматически (бэкапы, миграция мира,
  откат — тот же проверенный `Installer`). Кнопка **«Установить мод»** / **«Обновить мод»**
  выполняет ту же установку вручную.
- Если MSCLoader не установлен, на странице **Подключение** появляется кнопка
  **«Скачать MSCLoader»** с официальной ссылкой.
- Лаунчер подключается к Steam под AppID MSC **516750** через Steamworks.NET и
  нативные библиотеки из установленной игры. Используются `LobbyInvite_t` и
  `GameLobbyJoinRequested_t`, как в исходном лаунчере MWCoop. Игровые DLL не вшиты
  в лаунчер. Steam должен быть запущен и подключён к аккаунту с My Summer Car.
- После подключения лаунчера к Steam игра запускается дочерним процессом с
  AppID MSC и аргументами выбранного подключения. Повторного `-applaunch` нет:
  он мог бы повторно открыть лаунчер, указанный в параметрах запуска Steam.
  Для LAN доступен обычный прямой запуск. Старый API построения команды
  `GameArgs.Launch(settings, steamExe)` сохраняет маршрут через `-applaunch`.
- Настройки хранятся в `%APPDATA%\SummerCoop\launcher.ini`, сохраняются при запуске,
  установке и закрытии окна. Есть отдельная кнопка **«Сохранить»**.
- Диагностика: действия лаунчера, последние 150 строк `errors.log`, `output_log.txt`,
  кнопки открытия папок сохранения и игры.
- CLI без окна: `--detect [--log=PATH]`, `--print-args --mode=host-lan|join-lan|host-steam|join-steam|solo ...`
  и `--install --game=PATH [--profile=PATH] [--keep-other-mods] [--log=PATH]`.

## Оформление

Геометрия, цвета, боковая навигация и карточки подключения
перенесены из `vendor/MWCoop/launcher/ui.inc` и `uikit.inc` в `MwStyle.cs` и
`MwLauncherView.cs`. Летнее изображение из предыдущего лаунчера встроено в EXE
и заполняет окно с сохранением пропорций. Для замены можно положить `background.png`,
`background.jpg` или `background.jpeg` рядом с EXE или в его папку `assets`.
Кнопка солнца/луны переключает тему. Кнопки сверху сворачивают,
разворачивают и закрывают окно; за заголовок окно можно перетащить.

Установка мода, профиль мира, запуск и callbacks Steam используют действующий
MSC-адаптер. Карточка персонажа показывает имя; внешность настраивается в игре
через F10. Предпросмотр 3D и страницы зимних автомобилей оригинального лаунчера
не перенесены в эту версию.

## Сборка

Нужны Windows и `.NET Framework C# compiler` (как для мода). Полная цепочка:

```powershell
.\tools\build.ps1 -GamePath 'E:\SteamLibrary\steamapps\common\My Summer Car'
.\tools\package.ps1
```

`package.ps1` собирает EXE лаунчера с номером версии. Общее имя `SummerCoop-Launcher.exe` обновляется, если файл доступен для записи. Открытый старый лаунчер нужно закрыть перед запуском новой версии: экземпляры используют общий mutex. Отдельный установщик больше не собирается.
Только лаунчер из готового пакета:

```powershell
.\tools\build-launcher.ps1
```

Проверки лаунчера (19 тестов ядра, компиляция GUI на фиктивном пакете и проверки
настоящих WinForms-элементов; фиктивный EXE не публикуется):

```powershell
.\tools\test-launcher.ps1
# Дополнительно проверить загрузку реальных библиотек Steam из локальной MSC:
.\tools\test-launcher.ps1 -GamePath 'E:\SteamLibrary\steamapps\common\My Summer Car'
```

Константы версии в `launcher/LauncherCore.cs` (`LauncherInfo`) обязаны совпадать с
`src/Core/Model.cs` — это проверяет тест `launcher version constants match the mod protocol`.
GUI-проверки используют отдельный INI в `build`, проверяют загрузку сохранённых
параметров, все режимы, сохранение правок, ошибки ввода и отсутствие наложений
элементов при уменьшении окна. Снимки интерфейса сохраняются в
`build/launcher-tests/screenshots`; игра не запускается и мод не устанавливается.

## Использование

1. Запустите `SummerCoop-Launcher.exe` из любой папки.
2. Откройте **Настройки**: проверьте папку игры (находится в библиотеках Steam сама),
   профиль мира, способ запуска.
3. Если MSCLoader ещё не установлен, на странице **Подключение** нажмите **«Скачать MSCLoader»**
   и установите загрузчик в режиме **Game Folder**.
4. На **Главной** введите имя, выберите Steam или IP / VPN и нажмите **Создать** либо **Присоединиться**. На странице **Подключение** заполните показанные поля.
5. Нажмите **«Создать игру»**, **«Присоединиться»** или **«Играть»**: лаунчер сам сравнит обе DLL со
   своей сборкой и при расхождении установит или обновит мод (кнопка **«Установить мод»** /
   **«Обновить мод»** делает то же вручную), после чего запустит игру. Хост LAN открывает UDP на порту (по умолчанию 27842) или использует VPN
   (Radmin/ZeroTier). Хост Steam открывает **F10 → Пригласить через Steam**.

## Приглашения Steam

У приглашённого игрока должны быть установлен мод той же сборки и открыт Steam.
Если лаунчер открыт, входящее приглашение отображается на странице **Главная**.
Нажмите **«Принять и играть»**. Вводить номер лобби вручную не нужно. Можно также
принять приглашение в Steam: лаунчер обработает соответствующий callback.
При неудачной проверке игры, незавершённой установке или запущенной MSC приглашение
не пропадает. Если MSC уже запущена, закройте игру и снова примите приглашение.
Лаунчер не завершает игру принудительно и не переключает открытый мир.

Чтобы приглашение открывало **закрытый** лаунчер, один раз укажите его в параметрах
запуска MSC в Steam:

1. Переместите `SummerCoop-Launcher.exe` в постоянную папку.
2. В **Настройках** лаунчера нажмите **«Скопировать строку для Steam»**.
3. В Steam откройте **My Summer Car → Свойства → Общие → Параметры запуска** и
   вставьте скопированную строку вида `"D:\Games\SummerCoop-Launcher.exe" %command%`.

Steam запустит лаунчер с `+connect_lobby <64-битный ID>`. Приглашение появится в
его окне. Если окно уже открыто, вторая копия передаст ему приглашение и закроется.
Параметры Steam автоматически не изменяются. После перемещения EXE строку надо
обновить. Без этой настройки Steam при закрытом лаунчере запускает саму MSC.

Повторные callbacks одного лобби объединяются; можно выбирать между приглашениями
нескольких друзей. Приглашения в окне хранятся до 30 минут, межпроцессные сообщения
принимаются до 10 минут. Это локальные сроки отображения, а не гарантия доступности
лобби: хост должен продолжать игру. Разные сборки проверяются модом при соединении.

Проверено локально: разбор Steam-команд, передача между экземплярами, фильтрация
AppID, настоящие структуры и сигнатуры callbacks из MSC, обработка закрытого Steam,
выбор нужного лобби и интерфейс при минимальном размере окна. Реальное приглашение
и соединение **между двумя аккаунтами Steam** здесь не проверялись.

Пароль в команде запуска в диагностике маскируется целиком (`***`), включая пробелы
и кавычки. Ошибка скрытого порта LAN не мешает запуску Steam-режимов.

Steam описывает передачу приглашения и `+connect_lobby` в
[ISteamMatchmaking / LobbyInvite_t](https://partner.steamgames.com/doc/api/ISteamMatchmaking#LobbyInvite_t),
а принятые приглашения при запущенном приложении — в
[ISteamFriends / GameLobbyJoinRequested_t](https://partner.steamgames.com/doc/api/ISteamFriends#GameLobbyJoinRequested_t).

## Файлы

- `launcher/LauncherCore.cs` — настройки, построение аргументов, маскировка пароля в диагностике.
- `launcher/SteamInviteClient.cs` — Steamworks, приём приглашений, переподключение и освобождение callbacks.
- `launcher/SteamInvitation.cs` — приглашения, разбор команды Steam и межпроцессная очередь.
- `launcher/BackgroundArt.cs` — загрузка `background.*`, встроенная заглушка.
- `launcher/ModPayload.cs` — однократная распаковка встроенного пакета мода для установки, автообновления и CLI.
- `launcher/MainForm.cs` — WinForms-интерфейс с полями для выбранного режима.
- `launcher/Program.cs` — вход, CLI `--detect` / `--print-args` / `--install`.
- `launcher/app.manifest` — `asInvoker`, DPI-aware.
- `tools/Installer/InstallerCore.cs` — общий движок установки (проверки, бэкапы, миграция мира, откат).
- `tools/build-launcher.ps1` — компиляция с вшитым payload мода.
- `tests/Launcher/LauncherTests.cs`, `tests/Launcher/LauncherUiTests.cs`, `tools/test-launcher.ps1` — проверки ядра и интерфейса.
