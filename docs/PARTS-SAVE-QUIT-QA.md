# Проверка приборки, крепежа и выхода через туалет

Дата: 2026-10-19. Локальная сборка 0.5.0; сетевой формат не менялся.

## Игровые проверки

- `parts-toilet-workshop-04`: два изолированных процесса MSC, пять этапов затяжки/отпускания с чередованием хоста и гостя. Проверены 94 винта, включая обе клеммы аккумулятора и пять хомутов патрубков радиатора. Во всех этапах `Mismatches=0`, `WrongStages=0`, `WrongBolted=0`. Хомуты не перемещаются вдоль оси винта. Старые ремонтные пакеты не отменяют новые повороты.
- В том же запуске проверены две настоящие панели приборки с 11 физическими коллайдерами. Установленным панелям временно добавляется тестовое физическое тело при остановленной физике; положение и сохранённая установка деталей не меняются. Проверены переключение физических коллайдеров в триггеры и восстановление исходных значений. Отдельная составная тестовая деталь проверяет локальное/удалённое отпускание и сброс сцены с сохранением уже существовавших триггеров.
- `dashboard-mount-final`, хост: дополнительно проверено удаление Rigidbody при установке. Сохранившиеся коллайдеры восстанавливаются через `Sweep`; результат `Mount=PASS`. Короткий запуск использован для этой отдельной проверки, а не как полный повтор пяти этапов мастерской.
- `toilet-host-04`: один клик хоста сохраняет мир и возвращает обоих игроков в `MainMenu`. Лобби остаётся рабочим, автоматического повторного входа нет.
- `toilet-guest-01`: один клик гостя сохраняет мир у хоста; гость возвращается в `MainMenu`, хост остаётся в `GAME`. Подтверждена запись непустого актуального файла сохранения хоста.
- В полном запуске мастерской также прошли два этапа проводки и три этапа проверки ремня без расхождений.

Сырые отчёты находятся в `.local/<имя запуска>-host-report.txt` и `.local/<имя запуска>-client-report.txt`. Сверка SHA-256 с соответствующими `*-original-before.json` подтвердила, что исходные одиночные сохранения не изменились.

Игровые проверки вызывают нативные состояния PlayMaker и проверяют результаты, а не управляют физической мышью. Проверка коллизий оценивает настройки настоящих коллайдеров и их жизненный цикл; она не заменяет ручную проверку контактов во всех положениях деталей. Steam/WAN в эти сценарии не входят.

## Сборка и автономный EXE

- 131 проверка ядра и 41 проверка адаптера MSC прошли, включая настоящие локальные UDP-соединения и повторное открытие фонового ввода-вывода после возврата в меню.
- Прошли 28 проверок обновлений лаунчера, проверки выбора/сохранности миров и 18 проверок журнала изменений.
- Обе DLL пересобраны. Финальный EXE находится в `SummerCoop-Launcher/SummerCoop-Launcher.exe`; пользовательский INI сохранён. Извлечение ресурсов финального EXE подтвердило совпадение обеих DLL с `build/` по SHA-256.
- Microsoft Defender проверил финальные EXE и обе DLL: угроз не найдено. Отчёт: `build/defender-tests/parts-save-quit.json`.

SHA-256 финального EXE: `8D9E4F1EEAFE2AA0199ABBC39C1748353DE502BE3F319281848C1947AC77B834`.

Этот отчёт фиксирует локальные проверки до публикации GitHub Release.
