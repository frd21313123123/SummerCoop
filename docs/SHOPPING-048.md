# Покупки и пакеты MSC, 0.4.8

Хосту и гостям нужны обе DLL 0.4.8 одной сборки. Сетевой формат — **1048**.
Готовый автономный лаунчер: `SummerCoop-Launcher/SummerCoop-Launcher.exe`.

Исправлены три причины расхождения. MSC использует числовые таблицы `Items`
и `Spraycans`; старый механизм ожидал `Keys`/`Values` из MWC. В MSC выдачей
управляет `Spawner/ProductNameList::Logic`, а не `BagContentsStore`. Повтор
случайного выбора отдельно у каждого игрока давал разные предметы и ID.

Покупатель оплачивает заказ своей штатной кассой. Хост упорядочивает покупки
и извлечение. Товары выдаются штатными фабриками MSC, без переключения чужой
кассы и подмены локальной корзины. Соответствие количеств, ячеек пакета,
крупных товаров и уникальных аксессуаров берётся из действий самой кассы.
Один заказ создаёт один пакет. Крупные покупки выдаются отдельно.

При извлечении хост выбирает конкретную ячейку и передаёт её вместе с обеими
таблицами, свежестью, счётчиками фабрик и положением предмета. Все участники
создают один и тот же штатный объект. Полное открытие использует тот же
упорядоченный поток. Повторная команда с уже применённой версией игнорируется.
Реальная таблица баллончиков в проверенной MSC имеет 13 ячеек, несмотря на
значение `NumberOfCans=14` в штатной FSM; недостающая ячейка не читается.

Сохранение для подключающегося игрока содержит номер уже записанной операции.
Команды, поступившие во время загрузки после этого номера, сохраняются до входа
в мир; операции, уже включённые в сохранение, повторно не выполняются.
Передача сохранения ждёт завершения создания предметов.

Проверяются смешанная покупка гостя, личная оплата, корзина наблюдателя,
поочерёдное и одновременное извлечение, полное открытие, одновременная оплата,
наличие всех 12 выданных предметов и одинаковые штатные ID. Масляные фильтры
проверяются от покупки до установки гостем, затяжки хостом, откручивания и
снятия гостем. Проверяется подключение ещё одного клиента после этих действий.

Исправлены найденные привязки MWC:

| Механизм | Привязка MSC |
| --- | --- |
| Магазин | `STORE/StoreCashRegister/Register::Data` |
| Пакеты | `Spawner/CreateShoppingbag::ShoppingBag`, `Spawner/ProductNameList::Logic` |
| Телефон | `YARD/Building/LIVINGROOM/Telephone/Logic/PhoneLogic` |
| Почтовый ящик магазина | `STORE/LOD/Post Box/OrderTrigger::Open` |
| Цены топлива | `STORE::Fuelprices`, `Price98`, штатное состояние `Set table` для колонок |
| Своя покраска | `Systems/ImportCarTexture::Get`, `Material`, `CarTexture` |
| Кузов | `SATSUMA(557kg, 248)/Body/car body(xxxxx)` |

Названия автомобиля и справка лаунчера приведены к Satsuma и магазину Teimo.
Вместо зимнего логотипа DLL встраивается летний логотип проекта. Убраны
элементы выбора VIN/комплектации MWC и переходы к недоступным зимним дополнениям.
Функции, которых нет в MSC (ледовые гонки MWC, его парковки, клавиатуры телефонов,
зимние магазины и машины), не запускаются. Архивные исходники и ссылки на
происхождение MWCoop сохраняются для атрибуции.

Steam использует MSC app ID 516750, обновления — репозиторий SummerCoop,
загрузчик — MSCModLoader. Кэш списка выпусков вынесен из автономной папки
в `%LOCALAPPDATA%/SummerCoop/launcher-releases.json`.

Воспроизведение основной проверки:

```powershell
.\tools\build-mwcoop.ps1
.\tools\run-mwcoop-pair.ps1 -Run shopping-check -Port 28157 -Shopping -Duration 250
# После завершения обоих процессов:
.\tools\collect-shopping-results.ps1 -Run shopping-check
```

Результаты: [SHOPPING-048-RESULTS.txt](SHOPPING-048-RESULTS.txt). Используются
изолированные копии игры, скрытый рабочий стол и настоящая сеть UDP; одиночные
сохранения проверяются по SHA256. Это не проверка всей игры, WAN, двух аккаунтов
Steam, всех сторонних модов или визуального результата каждой покраски.
