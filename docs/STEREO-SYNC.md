# Автомагнитолы, двери и восстановление синхронизации

В F10 → «Синхронизация» кнопка **«Синхронизировать всё»** доступна и хосту,
и гостям. Гость получает повторные снимки состояния хоста; хост может запросить
их отправку всем находящимся в игре гостям. Повторное нажатие ограничено
интервалом в пять секунд. Получение больших снимков занимает некоторое время.

Восстановление повторяет обнаружение объектов и отправку зарегистрированных
состояний мира/FSM, взаимодействий, деталей и болтов, автомобильных дверей,
свободных предметов, жидкостей, использованных предметов и музыки. Снимки
заданий передают значения переменных, не повторяя оплату, создание предметов
или ввод игрока. Снимки мира и заданий отправляются порциями с учётом очереди
надёжного транспорта. Перезагрузка сохранения и повторное подключение не нужны.

## Причины исправленных сбоев

- Обычный повтор FSM передавал значения регулятора до выполнения его действия
  и мог повторять состояния мыши. При уменьшении громкости сравнение с нулём
  выполнялось с неправильным значением. `MscStereo` резервирует регуляторы
  `RadioVolume`/`RadioTuner` и передаёт отдельные шаги хосту. Результат возвращается
  всем игрокам, включая автора. Повторы сетевых пакетов не удваивают шаг, а
  перестановка пакетов не теряет более ранний шаг. При переподключении история
  запросов ушедшего игрока освобождается.
- Снимок CD раньше включал кнопку выбора трека/канала исходя только из режима
  радио/CD. Теперь он передаёт реальные состояния доступности кнопок и
  восстанавливает нативные последствия переключения режима/канала. Удалённое
  действие учитывает отдельные источники звука радио.
- Ключ съёмной двери строился по текущей иерархии машины. Теперь он основан на
  идентификаторе детали из базы игры. FSM двери заранее резервируется от общих
  сканеров; неготовые при установке состояния проверяются повторно. При смене
  тела/родителя сбрасываются старые данные владельца и защёлки.

## Проверки

```powershell
./tools/build-mwcoop.ps1 -GamePath .local/game-assembly-host -SkipVendorCopy
./tools/test-mwcoop-network.ps1
./tools/run-mwcoop-pair.ps1 -Run stereo-check -MusicOnly -HostGame game-assembly-host -ClientGame game-assembly-client
./tools/test-stereo-runtime.ps1 -Run stereo-check
./tools/run-mwcoop-pair.ps1 -Run door-check -AttachmentDoors -SeedProfile <копия_собранного_мира> -Duration 75
```

Для музыкального прогона нужны изолированные тестовые копии игры и музыкальные
файлы, используемые `MscMusicProbe`. Проверяются все три CD: футляры, извлечение,
возврат, вставка, воспроизведение, следующий трек и переключение режима. Отдельная
часть прогона оставляет штатные регуляторы включёнными и задаёт только условия
электропитания отсутствующей установки: громкость, одновременные шаги двух
игроков, отключение питания и кнопок, реальные кнопки F10, восстановление
испорченного значения FSM, радио HAYOSIKO/GIFU/FERNDALE/KEKMET/SATSUMA.
Тест двери после переустановки использует нативный вход открытия без вызова
сканера из тестовой кнопки.

Это проверки двух игровых процессов через LAN на одной машине. Они не заменяют
проверку между разными Steam-аккаунтами и всех возможных сборок электропроводки.
