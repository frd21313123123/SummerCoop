# Серая кнопка Steam: 0.1.11-alpha

13 октября 2026. В журнале последнего запуска 0.1.10-alpha обнаружены `Steamworks is not initialized` и `SteamAPI_Init() failed`. Steam отслеживал этот игровой процесс как AppID 516750, но API игры оставался недоступен. Точная причина отказа инициализации по этим журналам не установлена. Исходные журналы и идентификаторы аккаунта в выпуск не включены.

В 0.1.10 кнопка хоста отключалась без объяснения, а кнопка подключения к Steam оставалась доступной. В 0.1.11 обе кнопки используют готовность API игры и соединение с серверами Valve. Меню показывает причину отказа и проверяет состояние раз в секунду, включая скрытое меню. При восстановлении готовности кнопки становятся доступны; обработчик приглашений регистрируется и при позднем появлении API. Имя, введённое игроком, сохраняется.

Первое обращение к SteamManager и обработка аргументов запуска перенесены из Awake мода в Start, после начальных Awake игры. Это устраняет обращение во время загрузки мода. Мод не вызывает SteamAPI.Init, Shutdown или принудительный перезапуск игры; повторная проверка состояния не переинициализирует API после неудачного Init.

Лаунчер больше не подменяет запуск через Steam прямым запуском EXE, если steam.exe не найден. Для Steam-мультиплеера прямой способ запуска выдаёт объяснение; выберите «Автоматически» или «Steam». Прямой запуск для LAN/VPN и одиночного режима сохранён. Тесты формируют реальные ProcessStartInfo, но не запускают Steam и игру.

Если сообщение «API игры недоступен» остаётся, закройте игру, полностью выйдите из Steam и откройте Steam снова. Запускайте Steam и игру с одинаковым уровнем прав Windows, затем откройте My Summer Car из библиотеки. При сохранении отказа проверьте доступность игры на текущем аккаунте и журнал output_log.txt. По [документации Valve](https://partner.steamgames.com/doc/api/steam_api#SteamAPI_Init), Init может отказать при недоступном клиенте, неизвестном AppID, разных правах Windows или отсутствии лицензии. Работа магазина и списка друзей не подтверждает готовность API игрового процесса. LAN/VPN остаётся доступен.

Локально прошли 106 тестов ядра с TCP/UDP localhost, 21 проверка игровых классов, 12 тестов установщика и 14 тестов лаунчера с проверкой интерфейса. Три новых сценария проверяют маршруты Steam, отказ при отсутствующем клиенте и отказ прямого запуска Steam-мультиплеера с сохранением прямого LAN. Нативная проверка подтверждает сигнатуры SteamManager.Initialized и SteamUser.BLoggedOn без вызова Unity или Steam.

Готовый EXE прошёл обновление копии текущего мира с 0.1.10 и повторную установку. Сохранены все 38 342 сущности, ревизия 13 282, деньги 3 000 и байты нативных файлов. Повтор не изменил ни один файл профиля и его резервных копий. При реальной установке проверены те же данные, исходное одиночное сохранение, личные ключи и совпадение установленных DLL с проверенной сборкой. Контрольные суммы: [STEAM-READINESS-011-RESULTS.txt](STEAM-READINESS-011-RESULTS.txt).

Игру для этого выпуска не запускали. Успешная инициализация API, работа меню в Unity и подключение двух Steam-аккаунтов этими тестами не подтверждены. У всех участников должны стоять одинаковые DLL этого выпуска; установщик обновляет совместимый мир с резервной копией.
